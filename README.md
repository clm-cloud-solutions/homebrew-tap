# CLM Cloud Solutions Homebrew Tap

Homebrew tap for CLM Cloud Solutions open-source products.

## KubeBolt

Kubernetes operations platform: health, insights, operations, security and cost.

```bash
brew install clm-cloud-solutions/tap/kubebolt
kubebolt --kubeconfig ~/.kube/config
```

KubeBolt ships as a cask for macOS and Linux (amd64, arm64): Homebrew installs
the binary published on the GitHub release and never builds it, so it installs
whatever Xcode or Command Line Tools version the Mac has.

- **Website:** https://kubebolt.io
- **Documentation:** https://kubebolt.io/docs
- **Repository:** https://github.com/clm-cloud-solutions/kubebolt
- **License:** Apache-2.0

### Installed KubeBolt as a formula before?

Versions up to 2.3.0 were a formula. `brew upgrade` no longer updates it; switch
to the cask once:

```bash
brew uninstall --formula kubebolt
brew install clm-cloud-solutions/tap/kubebolt
```

Your data stays where it was: KubeBolt keeps it in `./data` of the directory you
run it from (or `KUBEBOLT_DATA_DIR`).

## How this tap works

The casks in this repository are generated by the release workflows of the
upstream repositories. Each one points to the platform binaries published on
GitHub Releases, with their SHA256 checksums.

Do not edit them by hand: the next release overwrites them.
